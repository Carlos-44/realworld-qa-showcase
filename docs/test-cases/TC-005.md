# TC-005: User can publish a new article
Linked criteria: F-02 AC-01 ([F-02](../features/F-02-articles.md))
Type: functional
Priority: P1
Tags: smoke
Automation: Automated (unverified)
## Preconditions
- A registered user, signed in (tests create one through the API).
## Steps
1. Open /editor.
2. Fill Article Title (unique), About and Body.
3. Click "Publish Article".
## Expected result
The URL is /article/<slug>, and the page shows the title as the main heading plus the body text.
