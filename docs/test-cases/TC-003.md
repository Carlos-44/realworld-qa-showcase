# TC-003: Login fails with invalid credentials
Linked criteria: F-01 AC-03 ([F-01](../features/F-01-authentication.md))
Type: negative
Priority: P1
Tags: regression
Automation: Automated
## Preconditions
- Signed out.
## Steps
1. Open /login.
2. Enter nobody@example.com and a wrong password.
3. Click "Sign in".
## Expected result
An error shows ("email or password is invalid"), the URL stays /login and the header still shows "Sign in".
