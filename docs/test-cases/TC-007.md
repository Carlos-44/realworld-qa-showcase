# TC-007: User can delete an article
Linked criteria: F-02 AC-03 ([F-02](../features/F-02-articles.md))
Type: functional
Priority: P2
Tags: regression
Automation: Automated (unverified)
## Preconditions
- A registered user, signed in (tests create one through the API).
- The signed-in user has published an article (created through the API).
## Steps
1. Open the article page.
2. Click "Delete Article".
3. Open the user's profile.
## Expected result
The app goes to /, and the profile shows "No articles are here... yet."
