# TC-008: User can favorite an article
Linked criteria: F-03 AC-01 ([F-03](../features/F-03-favorites.md))
Type: functional
Priority: P2
Tags: regression
Automation: Automated (unverified)
## Preconditions
- A registered user, signed in (tests create one through the API).
- The signed-in user has published an article (created through the API).
## Steps
1. Open / and click "Global Feed".
2. Find the article preview.
3. Click its heart button.
## Expected result
The favorites count changes from 0 to 1.
## Notes
- GitHub Issue #8 (existing ID, keep).
- e2e/tests/articles.spec.js. The user favorites their own article, which works around gap G-2. It doesn't cover favoriting another user's article.
- Unverified: the Playwright spec exists but hasn't passed in CI (red since a19dfa7), and it can't run locally without Docker.
