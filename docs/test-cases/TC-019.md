# TC-019: User can unfavorite an article
Linked criteria: F-03 AC-02 ([F-03](../features/F-03-favorites.md))
Type: functional
Priority: P2
Tags: regression
Automation: Not started
## Preconditions
- A registered user, signed in (tests create one through the API).
- The signed-in user has published an article (created through the API).
- The user has favorited it.
## Steps
1. Open / and click "Global Feed".
2. Click the article's heart button.
## Expected result
The count goes from 1 to 0, and the button is no longer highlighted.
