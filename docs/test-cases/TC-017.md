# TC-017: Publishing a duplicate title is rejected
Linked criteria: F-02 AC-05 ([F-02](../features/F-02-articles.md))
Type: negative
Priority: P2
Tags: regression
Automation: Not started
## Preconditions
- A registered user, signed in (tests create one through the API).
- The signed-in user has published an article (created through the API).
## Steps
1. Open /editor.
2. Use the existing article's exact title, and fill the other fields.
3. Click "Publish Article".
## Expected result
An error shows "must be unique", and no second article is created.
## Notes
- New case, no GitHub Issue yet.
