# TC-016: Publishing with a blank title, description or body is rejected
Linked criteria: F-02 AC-04 ([F-02](../features/F-02-articles.md))
Type: negative
Priority: P1
Tags: regression
Automation: Not started
## Preconditions
- A registered user, signed in (tests create one through the API).
## Steps
1. Open /editor.
2. Leave the title blank and fill the other fields.
3. Click "Publish Article".
4. Repeat with a blank description, then a blank body.
## Expected result
Each time an error shows "can't be blank", and no article is created.
